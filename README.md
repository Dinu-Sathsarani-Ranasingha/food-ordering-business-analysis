# 🍔 Food Ordering System – Business Analysis Project

## 📌 Project Overview
This repository contains the complete Business Analysis documentation for a **Food Ordering System**. The project demonstrates the Business Analysis lifecycle, from requirements gathering to documentation, user stories, sprint planning, and process modeling.

The objective is to improve the food ordering experience by providing customers with a simple online ordering platform while enabling restaurants to manage orders efficiently.

---

## 🎯 Project Objectives
- Analyze existing food ordering processes.
- Identify business problems and opportunities.
- Gather and document business requirements.
- Create functional and non-functional requirements.
- Develop Business Requirement Documents (BRD).
- Prepare Software Requirement Specification (SRS).
- Define User Stories for Agile development.
- Plan development sprints.
- Design UML diagrams.
