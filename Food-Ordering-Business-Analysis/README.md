# Food Ordering & Delivery System - Business Analysis Project

## 📌 Project Overview
This project focuses on analyzing and documenting the requirements of a Food Ordering & Delivery System using Business Analysis and Agile methodologies.

The project includes professional BA artifacts such as BRD, SRS, User Stories, UML diagrams, and Sprint Planning documentation.

---

## 📂 Project Artifacts
- Business Requirements Document (BRD)
- Software Requirements Specification (SRS)
- User Stories
- Use Case Diagram
- Activity Diagram
- Sprint Planning Document
